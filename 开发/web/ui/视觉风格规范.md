# 今日灵签视觉风格规范

> 适用对象：Codex、前端开发 Agent、UI 设计 Agent。  
> 目标：让后续设计和开发快速理解《今日灵签》要做成什么气质，避免做成传统抽签、算命广告或商务 App。

---

## 1. 核心风格定位

《今日灵签》的视觉方向定义为：

**纸感手账 × 轻手绘贴纸 × 情绪签章**

它应该像一本被用户随手翻开的私人小册子，也像咖啡店、文创店里的集章册：有纸张纹理、有手绘小贴纸、有印章感、有一点生活气，但整体要干净、克制、温柔。

核心关键词：

- 纸感
- 手绘
- 贴纸
- 印章
- 松弛
- 可爱
- 温暖
- 低饱和
- 轻仪式感
- 截图分享感

不要做成：

- 寺庙抽签
- 塔罗占卜
- 严肃国风
- 重玄学算命
- 商务 App
- 金融产品
- 高饱和卡通
- 大量复杂插画背景

---

## 2. 风格来源提炼

参考风格的核心不是“精致古风”，而是：

**像一个人认真记录生活的小本子，页面里贴着自己收集来的小印章、小杯子、小图案。**

需要吸收的关键特征：

### 2.1 奶油纸背景

背景不能是纯白，要有旧纸、奶油纸、再生纸的微妙质感。

可用特征：

- 米白
- 奶油白
- 浅灰米色
- 微颗粒纸纹
- 轻微做旧感
- 很浅的噪点纹理

避免：

- 纯白背景
- 强渐变背景
- 玻璃拟态
- 科技感背景
- 高亮荧光色

### 2.2 手绘贴纸感

图形元素应该像被手画出来的小贴纸，而不是标准图标库。

适合元素：

- 小狗
- 小云朵
- 小花
- 小星星
- 小爱心
- 小杯子
- 小签筒
- 小签纸
- 小印章
- 小纸条
- 胶带
- 手绘箭头

图形需要有一点“不完美感”：线条略抖、边缘略粗糙、颜色有颗粒感、填色不必特别均匀。

### 2.3 签章收集感

产品名叫《今日灵签》，但不要做成庙里抽签。更合适的方式是“签章收集感”：像每天收集一枚情绪印章。

可以设计：

- 每次抽签生成一枚今日签章
- 结果页像一张被盖章的小纸条
- 分享图像一张可以保存的签章卡
- 后续历史页可做成签章册
- 不同主题对应不同颜色签章

印章更像文创小章、咖啡店打卡章、旅行纪念章，而不是严肃朱印。

### 2.4 手账式排版

整体页面要松弛，不要过度商务网格化。

排版原则：

- 留白足够
- 元素之间有空气感
- 卡片像贴在纸上的小纸片
- 局部可轻微错落
- 图标不必完全机械居中
- 装饰只放在角落或卡片边缘
- 信息层级必须清楚

松弛不等于乱，整体依然要有明确阅读顺序。

## 3. 色彩规范

整体颜色低饱和、偏暖、偏纸感。不要使用过亮、过纯、过冷的颜色。

### 3.1 主色板

| 用途 | 色值 | 说明 |
|---|---:|---|
| 页面背景 | `#F7F1E6` | 奶油纸背景 |
| 卡片背景 | `#FFF9EE` | 暖白纸卡 |
| 次级底色 | `#EEE6DA` | 淡灰米色 |
| 主文字 | `#2F2722` | 墨棕黑 |
| 次文字 | `#7C7067` | 灰棕 |
| 边框线 | `#D8C6AD` | 浅牛皮纸线 |
| 主强调 | `#C47A3C` | 焦糖橙棕 |
| 辅助强调 | `#D65F47` | 朱砂橘红 |
| 柔和蓝灰 | `#9FB6C8` | 冷静辅助色 |
| 草木绿 | `#9BAA80` | 温柔自然感 |

### 3.2 主题色

| 主题 | 主色 | 气质 |
|---|---:|---|
| 关系 | `#D98572` | 温柔、靠近、暧昧 |
| 选择 | `#C78A45` | 犹豫、行动、轻鼓励 |
| 心境 | `#8FA58A` | 稳定、安顿、恢复 |

使用原则：

- 背景保持统一奶油纸感。
- 主题色只用于卡片边框、图标、小印章、小按钮。
- 一页不要出现超过 3 个强调色。
- 结果页主句区域尽量少用颜色，让文字成为中心。
- 分享图可以更可爱一点，但仍要低饱和。

## 4. 字体规范

整体字体气质：**手账 + 打字机 + 轻手写**。

建议方向：

| 类型 | 字体方向 | 用途 |
|---|---|---|
| 品牌标题 | 手写感中文 / 温柔宋体 | 今日灵签 |
| 页面标题 | 手写感中文 / 圆润标题字 | 页面主标题 |
| 正文 | 清晰中文黑体 / 圆体 | 说明文案 |
| 数字 / 日期 | 等宽字体 / 打字机字体 | 日期、签号、页码 |
| 印章文字 | 复古章印感字体 | 今日签章、Lucky Day |

建议字号：

| 元素 | 字号 |
|---|---:|
| 品牌名 | 28-34 |
| 页面主标题 | 24-30 |
| 卡片标题 | 18-22 |
| 结果主句 | 26-34 |
| 正文说明 | 13-16 |
| 日期 / 辅助信息 | 12-14 |
| 按钮文字 | 15-17 |

文案气质：

- 像朋友轻轻说一句
- 短、轻、有画面
- 有陪伴感
- 不替用户做决定
- 不做命运判断

避免：

- 命中注定
- 你必须
- 一定会
- 这是天意
- AI 为你分析
- 精准预测

## 5. 图形元素规范

### 5.1 图标风格

图标应采用：

- 手绘线条
- 边缘略不规则
- 低饱和填色
- 简单表情
- 贴纸白边
- 轻微颗粒质感

主题对应图形：

| 主题 | 图形建议 |
|---|---|
| 关系 | 两颗小心、两只小鸟、抱着杯子的云朵、小狗 |
| 选择 | 路牌、分叉线、小箭头、天平、两张小纸条 |
| 心境 | 云朵、嫩芽、小杯子、水波、睡觉小人 |
| 抽签 | 杯子签筒、纸签、小印章、落下来的签 |
| 分享 | 邮戳、胶带、纸片、星星、小花 |

### 5.2 装饰规则

装饰只能轻点缀，不能抢内容。

可使用：

- 小星星
- 手绘短线
- 胶带贴纸
- 纸张折角
- 虚线分割
- 小印章
- 小花
- 小狗 / 小云朵

控制规则：

- 每屏主要装饰不超过 3 处。
- 装饰不能影响阅读。
- 装饰优先放在角落、卡片边缘、按钮旁。
- 不要大面积铺满背景。
- 不要使用复杂插画背景。

## 6. 页面规范

### 6.1 首页

目标：让用户愿意点一个主题。

结构：

1. 顶部：产品名 `今日灵签`
2. 日期：如 `5月31日 周六`
3. 主标题：`今天想先聊哪一块？`
4. 副标题：`不替你拿主意，只想在你有点乱的时候，给你一句能听进去的话。`
5. 三个主题卡片：关系 / 选择 / 心境
6. 底部轻提示

设计建议：

- 三个主题卡片像三张贴纸卡。
- 每张卡片配一个手绘小图标。
- 卡片可以有轻微不同底色，但都要低饱和。
- 底部可以放小狗 / 小云朵气泡。
- 顶部可以有小邮戳式印章。

### 6.2 轻场景选择页

目标：让用户觉得“这句像我”。

设计建议：

- 卡片像贴在纸上的便签。
- 选中态用红橙色小圆勾。
- 每张卡片右侧可放一个小插画。
- 不要像问卷题，要像在选一句小纸条。

### 6.3 状态选择页

目标：进一步提升结果代入感。

设计建议：

- 四个选项用统一卡片。
- 左侧手绘小图标，右侧单选圆圈。
- 图标可用火苗、天平、小杯子、嫩芽。
- 选中态用细描边 + 小勾，不要强色块。

### 6.4 抽签页

目标：形成轻仪式感。

设计建议：

- 签筒可以像一个有花纹的杯子。
- 纸签可以有手绘木纹和小花。
- 背景保持干净，只放少量星星、小花。
- 按钮使用焦糖橙棕色。

### 6.5 抽签过渡页

目标：补足等待的仪式感。

设计建议：

- 签纸轻微倾斜。
- 配少量手绘动线。
- 页面更空，像等待一张纸慢慢落下。
- 不要复杂动画或炫光。

### 6.6 结果页

目标：让用户觉得“这句像我”，并愿意保存。

设计建议：

- 主句像被胶带贴在纸上的签文卡。
- 加一个圆形“今日灵签”印章。
- 解释区块用轻卡片，不要太重。
- 主句必须最大、最醒目。
- 结果页是截图核心，装饰更要克制。

### 6.7 分享图弹层

目标：让用户自然保存或转发。

设计建议：

- 分享图像一张独立贴纸卡。
- 使用纸片边框、胶带、小印章。
- 不要塞太多解释。
- 重点是主句好读、好截图、好转发。

---

## 7. 动效规范

动效要轻，不要炫。

适合动效：

- 卡片点击时轻轻下压
- 选中时小勾弹出
- 签纸轻微落下
- 印章轻盖一下
- 分享图弹层从底部浮起
- 小星星轻微闪一下

不适合动效：

- 大幅旋转
- 强烈粒子爆炸
- 复杂光效
- 强弹跳
- 游戏化过重

## 8. Codex 提示词

```text
请为《今日灵签》设计一套移动端 H5 / 小程序 UI。风格为“纸感手账 × 轻手绘贴纸 × 情绪签章”。整体要温柔、可爱、松弛、低饱和，有奶油纸质感，像一本私人手账或咖啡店集章册。界面中可以使用手绘小贴纸、邮戳、胶带、纸片、印章、小花、小狗、小杯子、签筒等元素，但必须克制，不能堆满。字体要有手写感和打字机感，中文正文保持清晰易读。配色以奶油白、墨棕、焦糖橙棕、低饱和草木绿、蓝灰为主。页面要有截图分享感，尤其结果页和分享图要像一张可以保存的小纸条签文。不要做成传统寺庙抽签、重玄学、重国风、商务 App 或高饱和卡通风。
```

---

## 9. 最终判断标准

一版设计是否符合这个风格，可以用以下问题判断：

1. 第一眼是否温柔、可爱、松弛？
2. 是否有纸张、手账、贴纸、印章的感觉？
3. 页面是否干净，不拥挤？
4. 图形元素是否像手绘，而不是模板图标？
5. 结果页是否让人想截图保存？
6. 分享图是否像一张可以发给朋友的小纸条？
7. 整体是否避开了传统玄学和商业 App 感？

如果以上大多数答案是“是”，这套风格就是对的。
